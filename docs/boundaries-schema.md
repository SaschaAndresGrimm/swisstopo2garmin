## Facts that shape the code

1. **Commune names are not unique**: 1 appear more than once (`Greifensee` ×2). A picker must show the canton alongside the name, exactly as the place search does.
2. **Geometry is MULTIPOLYGON throughout.** A commune can be several disjoint pieces (an exclave, or a lake share), so a mask has to be a union of polygons, not one ring.
3. **`bfs_nummer` is the stable identifier for a commune**, `kantonsnummer` for a canton, `bezirksnummer` for a district. Names change; numbers are what a saved recipe should store.
4. **11 rows are lake surface, not communes** (`objektart = 'Kantonsgebiet'`). Offering them in a commune picker would be wrong.
5. **`einwohnerzahl` is present for every level**, so a picker can rank by population the way the place search does.
